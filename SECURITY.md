# Security Policy

## Reporting a vulnerability
Do not disclose exploitable vulnerabilities in public issues. Contact the repository owner privately using the security contact configured in the GitHub repository settings.

## Security posture and limitations
This is an interview/demo prototype, not a production-ready service. It currently lacks production authentication, authorization, rate limiting, abuse/phishing detection, secret management, durable workflow storage, sandbox isolation for generated code, and a full dependency/SAST pipeline.

Never expose this demo directly to the public internet with sensitive data. Do not provide agents with production credentials or unrestricted shell/network access.
